Vice Cover Studio v4 — turn your photos into GTA-style multi-panel movie-poster cover art: Poster Ink duotone grades with halftone, eight layouts (including a Vice File police case-file genre with stat bars, a Pop-Out Hero, and a Polaroid portrait mode), striped retro-chrome 3D titles, a full Poster Kit (role tags, press quote + outlet, billing block, gold seal, VOL tag, COMING SOON pill, barcode), per-panel grades and crops with face-safe crop and a Mark face helper, and PNG export in 1080×1080, 1080×1350 and 1920×1080. Eight named cast samples, undo/redo, shuffle, presets. Offline, no uploads, no Rockstar assets — fonts Anton, Pacifico and Oswald under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add photos, pick a layout and grade, write your caption, export the PNG.
